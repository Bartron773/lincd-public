<h2 class="mt-6 mb-2 font-semibold text-2xl" data-streamdown="heading-2">What it is</h2>
<ul class="list-inside list-disc whitespace-normal [li_&amp;]:pl-6" data-streamdown="unordered-list">
<li class="py-1 [&amp;&gt;p]:inline" data-streamdown="list-item"><span class="font-semibold" data-streamdown="strong">Stateful vs Stateless</span>: Unlike chatbots that forget after session, Linc(d) tracks facts → habits with persistent memory.</li>
<li class="py-1 [&amp;&gt;p]:inline" data-streamdown="list-item"><span class="font-semibold" data-streamdown="strong">4-Part Memory</span>: Working / Episodic / Procedural / Semantic — tracks facts to habits.</li>
<li class="py-1 [&amp;&gt;p]:inline" data-streamdown="list-item"><span class="font-semibold" data-streamdown="strong">Continuous Cognitive Loop</span>: Perception → Integration → Inference → Adaptation</li>
<li class="py-1 [&amp;&gt;p]:inline" data-streamdown="list-item"><span class="font-semibold" data-streamdown="strong">Cognitive States</span>: Exploratory / Execution / Overload detection</li>
<li class="py-1 [&amp;&gt;p]:inline" data-streamdown="list-item"><span class="font-semibold" data-streamdown="strong">Cognitive Compiler</span>: Transforms thoughts &amp; data into Reports, Slide Decks, Podcasts, Scripts.</li>
</ul>
