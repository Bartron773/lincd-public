# Bartica — Public Dashboard Reference

This file is a public-safe display profile for the Bartica skill.

It is designed to help an agent present Bart as a whole person without flattening him into a personality score or silently promoting inference into fact.

## Display name

Bart

## Public-facing summary

Bart is a reflective strategist, aesthetic systems thinker, creative technologist, and relationally intelligent builder who works across photography, AI experimentation, personal knowledge systems, digital culture, and human-centered interface ideas.

He tends to value meaning-preserving structure, autonomy, low-friction systems, aesthetic coherence, emotional truth, and tools that make complexity easier to navigate without making the human disappear.

## Bartica / robotOS

Bartica is the personal interface layer of the broader Linc(d) architecture.

It is intended as a low-friction hub that can bring together:

- thought and memory
- creative production
- AI collaboration
- media and cultural discovery
- personal knowledge structure
- active projects
- context-aware interfaces

The design direction is modular, transparent, consent-based, human-centered, and optimized for fast navigation across iPhone, iPad, and Mac.

## Dashboard modules

### Context Core

Public-safe context may be grouped under:

- Identity
- Environment
- Taste
- Reasoning

Each item should preserve its status when known: confirmed, proposed, witnessed, or session-specific.

### AI Agents

Show active AI collaborators or model roles only when known from current context. Do not imply that a model has memory or access it does not actually possess.

### Knowledge Graph

Use the graph to reveal relationships among projects, interests, references, tools, and creative work.

The graph should serve Bart rather than profile him. Prefer local, transparent, consent-based relationships over opaque scoring.

### Today's Flow

Summarize current momentum, open loops, or creative direction when recent context exists.

Do not fabricate a current state from old history.

### Connected Systems

May include approved tools, archives, media sources, creative platforms, or services that are actually connected or explicitly referenced in the current session.

### Focus Now

Useful public-safe focus labels include:

- Photography
- AI Experiments
- Music + Drive
- Ideas → Build
- Future Tech

Treat these as navigational lenses, not permanent categories.

### Live Insights

Insights may surface patterns such as the importance of beauty, nature, scenic movement, aesthetic coherence, or low-friction structure.

Any such interpretation must remain visibly an observation or proposal unless Bart has explicitly confirmed it.

## Design character

Bartica should feel like a calm personal operating surface rather than an enterprise analytics console.

Prefer:

- strong hierarchy
- clean typography
- modular cards or panels
- restrained motion
- high legibility
- meaningful negative space
- visual richness only where it carries meaning

Avoid:

- gamified personality scoring
- surveillance aesthetics
- excessive charts for their own sake
- fake precision
- dense corporate dashboard clutter

## Governance

Bartica is a display and interaction layer.

Linc(d) remains the authority for context permissions, provenance, memory state, and session contracts.

When in doubt, preserve uncertainty and ask for confirmation rather than declaring an interpretation true.
